# Human: Fall Flat 자동 벽타기

Human: Fall Flat 에서 평평한 벽을 자동으로 오르는 매크로입니다. 두 가지 파일이 있습니다.

| 파일 | 실행 방법 | 특징 |
| --- | --- | --- |
| `hff_wall_climb.ahk` | [AutoHotkey v2](https://www.autohotkey.com/) 설치 후 더블클릭 | 가장 쉬움. 설정은 파일 상단 변수 수정 |
| `hff_wall_climb.py` | Python 3.9+ (Windows) | 외부 패키지 없음, 명령줄 옵션으로 조정 |

## 게임 조작 원리

- 마우스 버튼을 **누르고 있는 동안에만** 그 팔이 올라가고, 카메라(시선) 방향을 따라갑니다.
- 올라간 손이 벽에 닿으면 자동으로 잡습니다.
- 잡은 상태에서 **아래를 보면 몸이 끌려 올라갑니다** (풀업).

## 두 가지 방식

**pull (기본) - 풀업 재잡기.** 스피드런에서 쓰는 Extended Climb 방식입니다.
1. 양손으로 벽을 잡습니다.
2. 아래를 봐서 몸을 끌어올립니다.
3. 한 손만 놓고, 빠르게 위를 보면서 그 손을 다시 눌러 더 높은 곳을 잡습니다.
4. 손을 바꿔가며 반복합니다. 항상 한 손은 잡고 있으므로 떨어지지 않습니다.

**swing - 스윙 잡기.** Steam 커뮤니티 가이드 방식입니다.
1. 한 손으로 매달립니다.
2. A/D 키로 몸을 좌우로 흔듭니다.
3. 흔들림의 정점에서 반대 손을 눌러 더 높은 곳을 잡고, 아래쪽 손을 놓습니다.

## 사용법

1. 게임에서 오르고 싶은 벽 **바로 앞에 서서 벽을 바라봅니다.**
2. 매크로를 실행합니다.
   - AutoHotkey: `hff_wall_climb.ahk` 더블클릭. 트레이에 초록색 H 아이콘이 생기고 알림이 뜹니다.
   - Python: `python hff_wall_climb.py` (swing 방식은 `--mode swing`)
3. 게임 창이 활성화된 상태에서 **F6** 을 누릅니다.
   매크로가 위를 보고 → 양손을 들고 → 앞으로 점프해서 벽을 잡은 뒤 → 오르기 시작합니다.
4. 다시 **F6** 을 누르면 멈추고 손을 모두 놓습니다. **F8** 은 프로그램 종료입니다.

## 설정 조정

마우스 감도와 프레임에 따라 값을 맞춰야 합니다. 가장 먼저 만질 값은 `LookPixels` 입니다.

| 항목 | AHK 변수 | Python 옵션 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| 시선 이동량 | `LookPixels` | `--look` | 350 | 위를 보는 상태와 아래를 보는 상태 사이의 마우스 이동량. 게임 감도가 높으면 줄이고 낮으면 늘리세요. 시작 시 위를 보고 있을 때 이 값만큼 내리면 발밑이 보여야 합니다. |
| 빠른 위 보기 | `FastLookMs` | `--fast-look` | 40ms | 재잡기 직전 위를 보는 시간. 빠를수록 몸이 내려오기 전에 높이 잡습니다. |
| 느린 아래 보기 | `SlowLookMs` | `--slow-look` | 150ms | 몸을 끌어올릴 때 시선을 내리는 시간입니다. |
| 자동 점프 | `AutoJump` | `--no-jump` 로 끔 | 켬 | 시작 시 앞으로 점프해서 벽을 잡습니다. 이미 잡을 수 있는 높이면 꺼도 됩니다. |
| 잡기 대기 | `GrabWaitMs` | `--grab-wait` | 900ms | 점프 후 손이 벽을 잡을 때까지 기다리는 시간입니다. |
| 풀업 대기 | `PullHoldMs` | `--pull-hold` | 300ms | [pull] 아래를 본 뒤 몸이 올라올 때까지 기다리는 시간입니다. |
| 재잡기 지연 | `RegrabDelayMs` | `--regrab-delay` | 20ms | [pull] 위를 본 뒤 손을 다시 누르기까지의 지연입니다. |
| 안정화 대기 | `SettleMs` | `--settle` | 350ms | 다시 잡은 손이 벽을 붙들 때까지 기다리는 시간입니다. |
| 스윙 시간 | `SwingMs` | `--swing` | 450ms | [swing] 한쪽으로 흔드는 시간입니다. |
| 스윙 잡기 | `SwingGrabMs` | `--swing-grab` | 300ms | [swing] 정점에서 반대 손을 눌러 잡는 시간입니다. |
| 스윙 횟수 | `SwingCycles` | `--swing-cycles` | 1 | [swing] 잡기 전에 흔드는 왕복 횟수입니다. |
| 시작 손 | `StartLeft` | `--start-right` | 왼손 | 먼저 재잡기 / 매달리는 손입니다. |
| 이동/점프 키 | `KeyForward` 등 | `--key-forward` 등 | W A D Space | 게임 키 설정을 바꿨다면 맞춰 주세요. |
| 창 확인 | `WindowMatch` | `--window` | `Human` | 제목에 이 문자열이 포함된 창이 활성일 때만 시작합니다. |

## 잘 안 될 때

| 증상 | 조치 |
| --- | --- |
| 시작 점프 후 벽을 못 잡는다 | 벽에 더 가까이 서세요. 점프 없이도 손이 닿는 높이면 `AutoJump` 를 끄세요. |
| 몸이 올라갔다가 다시 제자리 | `LookPixels` 가 너무 작아 아래를 충분히 못 보는 상태입니다. 값을 늘리세요. |
| 시선이 벽 옆으로 돌아간다 | 마우스는 세로로만 움직입니다. 벽을 정면으로 바라보고 시작하세요. |
| 재잡기가 같은 높이만 잡는다 | `FastLookMs` 를 줄이고 `RegrabDelayMs` 를 0 으로 해보세요. 그래도 안 되면 `--mode swing` 을 써보세요. |
| 손이 잡았다가 바로 놓친다 | 손과 몸의 거리가 너무 멀면 게임이 강제로 놓게 합니다. `LookPixels` 를 조금 줄이세요. |
| 게임 콘솔 사용 가능 | `~` 키로 콘솔을 열고 `climbcheat` 를 입력하면 더 높이 잡을 수 있어 매크로가 훨씬 잘 됩니다. |

## 동작 미리 보기 (입력 없이)

Python 버전은 실제 입력을 보내지 않고 순서만 확인할 수 있습니다. Windows 가 아니어도 됩니다.

```
python hff_wall_climb.py --dry-run 2
python hff_wall_climb.py --mode swing --dry-run 2
```
