# Human: Fall Flat 자동 벽타기

Human: Fall Flat 에서 벽을 자동으로 오르는 매크로입니다. 두 가지 버전이 있습니다.

| 파일 | 실행 방법 | 특징 |
| --- | --- | --- |
| `hff_wall_climb.py` | Python 3.9+ (Windows) | 외부 패키지 없음, 명령줄 옵션으로 세부 조정 |
| `hff_wall_climb.ahk` | [AutoHotkey v2](https://www.autohotkey.com/) | 스크립트 더블클릭으로 바로 실행 |

## 동작 원리

게임에서 사람이 벽을 오르는 손동작을 그대로 반복합니다.

1. 한 손으로 벽을 잡은 상태에서 마우스를 위로 올려 반대 손을 든다.
2. 반대 손 버튼을 눌러 더 높은 곳을 잡는다.
3. 원래 손을 놓는다.
4. 마우스를 아래로 내려 몸을 끌어올린다.
5. 손을 바꿔 반복한다.

마우스 이동은 상대 좌표로 보내기 때문에 게임의 Raw Input 설정과 무관하게 동작합니다.

## 사용법

1. 게임에서 오르고 싶은 벽에 몸을 붙이고 카메라를 살짝 위로 향합니다.
2. 매크로를 실행합니다.
   - Python: `python hff_wall_climb.py`
   - AutoHotkey: `hff_wall_climb.ahk` 더블클릭
3. 게임 창이 활성화된 상태에서 **F6** 을 누르면 벽타기가 시작됩니다.
4. 다시 **F6** 을 누르면 멈추고 잡고 있던 손을 모두 놓습니다.
5. **F8** 을 누르면 프로그램이 종료됩니다.

## 세부 조정

벽 높이, 마우스 감도, 프레임에 따라 값을 조정해야 할 수 있습니다.

| 항목 | Python 옵션 | AHK 변수 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| 팔 이동 거리 | `--reach` | `ReachPixels` | 420 | 클수록 팔을 더 높이 뻗습니다. 손이 벽을 놓치면 줄이세요. |
| 스텝 크기 | `--step` | `StepPixels` | 12 | 작을수록 부드럽지만 느립니다. |
| 스텝 간격 | `--step-delay` | `StepDelay` | 0.004초 / 4ms | 마우스 이동 속도입니다. |
| 잡기 간격 | `--grab-delay` | `GrabDelay` | 0.10초 / 100ms | 잡기와 놓기 사이 대기입니다. 손이 미끄러지면 늘리세요. |
| 끌어올리기 대기 | `--pull-delay` | `PullDelay` | 0.15초 / 150ms | 몸이 따라올 시간을 줍니다. |
| 시작 손 | `--start-right` | `StartLeft` | 왼손 | 첫 번째로 벽을 잡는 손입니다. |
| 토글 키 | `--toggle-key` | `F6::` | F6 | 시작/정지 키입니다. |
| 종료 키 | `--exit-key` | `F8::` | F8 | 프로그램 종료 키입니다. |
| 창 확인 | `--window` | `WindowMatch` | `Human` | 제목에 이 문자열이 포함된 창이 활성일 때만 시작합니다. 빈 문자열이면 검사하지 않습니다. |

예시:

```
python hff_wall_climb.py --reach 500 --grab-delay 0.15 --toggle-key home
```

## 동작 미리 보기 (입력 없이)

실제 입력을 보내지 않고 어떤 순서로 움직이는지 확인할 수 있습니다. Windows 가 아닌 환경에서도 동작합니다.

```
python hff_wall_climb.py --dry-run 2
```

## 팁

- 게임 내 마우스 감도가 높으면 `--reach` 를 줄이고, 낮으면 늘리세요.
- 손이 벽을 잡지 못하고 헛돌면 카메라를 조금 더 위로 향한 뒤 다시 시작하세요.
- 창 활성 검사는 실수로 다른 프로그램에 클릭이 들어가는 것을 막기 위한 안전장치입니다.
